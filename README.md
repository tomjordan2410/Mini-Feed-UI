# Mini Feed Simulator

Building on my Mini Feed that was initially built to function only in Javascript, this now incorporates DOM manipulation to create a User Interface Mini Feed simulator. 


## How to Use

### Make a Post

Add a username and your post content and then hit the post button. The post will render in the feed below. If no content is entered into either box, no post will render. Each post comes with a like button and a delete button.

### Sort By

As default, the posts are sorted in order of their time of posting. You can change this to sort by the number of likes using the dropdown menu.

### Filter Posts

You can filter posts by a specific user using the filter searchbox. To undo this, clear the searchbox and re-hit search.
